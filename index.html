PROJECT INFORMATION

About This Web GIS

An interactive Web GIS application for exploring selected cities and weather-station information across Pakistan.

🗺️

Interactive Mapping

The application provides interactive navigation using zoom, pan, layer switching, and multiple basemap options.

🏙️

City Information

The city dataset contains 20 selected locations with city name, province or region, and city classification.

🌦️

Weather Information

The weather-station dataset contains temperature and rainfall values for 20 selected locations.

💻

Web GIS Technologies

Developed using HTML, CSS, JavaScript, GeoJSON and the Leaflet web-mapping library.

Data sources: City and weather-station locations are provided through the project's GeoJSON datasets. Live weather conditions are retrieved from Open-Meteo and displayed for the mapped locations.

Mapping: OpenStreetMap and Esri World Imagery are used as basemap sources.

This interactive Web GIS presents selected cities and weather stations across Pakistan. Users can explore geographic locations, view attribute information and switch between different map layers and basemaps.

Map Layers

  • OpenStreetMap
  • Satellite Imagery
  • Major Cities
